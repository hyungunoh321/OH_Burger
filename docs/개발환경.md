| JDK | Temurin 21 | `C:\Program Files\Eclipse Adoptium\jdk-21...` |

## 프로젝트 구조

```
OH_Burger/                      이클립스 Dynamic Web Project (저장소 루트)
├─ src/main/java/               Java 소스
│  ├─ ohburger/common/          DB 연결, 필터 등 공통 코드
│  ├─ ohburger/web/             서블릿
│  ├─ db.properties             DB 접속 정보 (Git 제외)
│  └─ db.properties.example     접속 정보 양식
├─ src/main/webapp/             웹 루트
│  ├─ css/, js/                 정적 파일
│  ├─ index.jsp                 /home 으로 이동
│  └─ WEB-INF/
│     ├─ web.xml
│     ├─ lib/                   라이브러리 jar
│     └─ views/                 JSP (직접 접근 불가, 서블릿이 forward)
├─ db/                          스키마와 초기 데이터 SQL
└─ docs/                        설계 문서, 프로토타입, 제안서
```

## DB 준비

```bash
mysql -u root -p --default-character-set=utf8mb4 -e "source db/schema.sql"
mysql -u root -p --default-character-set=utf8mb4 -e "source db/data_burger.sql"
```

웹 앱은 root 가 아니라 전용 계정 `ohburger` 로 접속한다 (oh_burger DB에 대한 조회 · 추가 · 수정 · 삭제 권한만 있음).
접속 정보는 `src/main/java/db.properties` 에 있고, 다른 PC에서는 `db.properties.example` 을 복사해 값을 채운다.

```sql
CREATE USER 'ohburger'@'localhost' IDENTIFIED BY '비밀번호';
GRANT SELECT, INSERT, UPDATE, DELETE ON oh_burger.* TO 'ohburger'@'localhost';
```

## 이클립스에서 여는 법 (처음 한 번)

1. `C:\dev\eclipse\eclipse.exe` 를 실행한다. 작업 폴더(workspace)는 `C:\dev\workspace` 처럼 **프로젝트 폴더가 아닌 곳**으로 정한다.
2. Tomcat 등록: `Window > Preferences > Server > Runtime Environments > Add`
   - `Apache Tomcat v9.0` 선택 → Next
   - Tomcat installation directory: `C:\dev\apache-tomcat-9.0.124`
   - Name 은 기본값 **`Apache Tomcat v9.0`** 그대로 둔다 (프로젝트 설정이 이 이름을 찾는다)
3. 프로젝트 불러오기: `File > Import > General > Existing Projects into Workspace`
   - Select root directory: 이 저장소를 받은 폴더 (`OH_Burger`)
   - "Copy projects into workspace" 는 **체크하지 않는다**
4. 실행: 프로젝트 우클릭 → `Run As > Run on Server` → `Tomcat v9.0 Server` 선택 → Finish
5. 브라우저에서 `http://localhost:8080/OH_Burger/` 가 열리고 브랜드별 버거 수가 나오면 정상이다.

## 이클립스 없이 확인하는 법

`C:\dev\run-tomcat.bat` 을 실행하면 Tomcat 이 프로젝트 폴더를 바로 띄운다
(`conf/Catalina/localhost/OH_Burger.xml` 이 `src/main/webapp` 과 `build/classes` 를 가리킨다).
이 방식은 Java 코드를 직접 컴파일해 `build/classes` 에 넣어야 한다.

이클립스에서 서버를 띄운 상태로 이 배치 파일을 실행하면 8080 포트가 겹치므로 둘 중 하나만 실행한다.
